# Shared form UI and subscription correction — 2026-10-17

## Changes

- Replace the global text-input outline that drew a square inside prefixed/suffixed fields. Standalone text controls get a rounded boundary ring; shared `.field-shell` containers own focus for handle, subscription price and library search. Keyboard focus, invalid states and forced-color outlines are retained. Rich-text focus belongs to the editor boundary.
- Profile subscription price uses a numeric keyboard without a native spinner, an unshrinking 30-day suffix and inline whole-number validation. Blank/zero/positive prices retain the existing API contract. Name/handle validation focuses the first invalid field; failed saves preserve values and release the save button.
- Login, signup and email verification share inline constraint feedback rather than floating native validation bubbles. Error descriptions are associated with the focused control and cleared on correction. Authentication forms default to POST so a native fallback cannot put credentials in a GET URL.
- Add missing accessible labels to collection-name and report-detail controls and increase report-control touch targets. Keep OTP text larger than the mobile 16px input minimum. Hide browser number spinners without removing numeric constraints or keyboard stepping.
- When Stripe checkout is enabled, hide the mock author subscription action and membership price/perk sales pitch. Show an honest upcoming-membership notice and an explore-stories action. The subscription POST endpoint rejects both new mock subscriptions and mock renewals with 409. Existing demo access and authenticated cancellation remain available; this does not implement recurring Stripe billing.
